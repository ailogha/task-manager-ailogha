# 🗂️ نظام إدارة المهام والمشاريع المتقدم

### منصة احترافية لإدارة المهام والمشاريع مدعومة بقاعدة بيانات SQLite محلية والذكاء الاصطناعي

</div>

---

## 📋 نظرة عامة

نظام شامل لإدارة المشاريع والمهام مع واجهة عربية كاملة (RTL)، يدعم لوحات كانبان، لوحات تحكم تحليلية، إدارة مستخدمين بصلاحيات متقدمة، ومساعد ذكي مدعوم بـ Gemini AI. جميع البيانات تُحفظ بشكل دائم في قاعدة بيانات SQLite محلية.

## ✨ المميزات الرئيسية

### 📊 لوحة التحكم (Dashboard)
- إحصائيات حية للمشاريع والمهام
- رسوم بيانية تفاعلية (Recharts) لتوزيع المهام وحالاتها
- جدول المهام الحديثة
- مؤشرات الأداء (KPIs)

### 🗂️ إدارة المشاريع
- إنشاء وتعديل وحذف المشاريع
- تصنيف المشاريع حسب الفئات (برمجيات، تسويق، تصميم، عام)
- تتبع نسبة التقدم لكل مشروع
- ألوان مميزة لكل مشروع

### 📋 لوحة كانبان تفاعلية
- أربع مراحل سير العمل (قيد الانتظار ← قيد التنفيذ ← قيد المراجعة ← مكتملة)
- نقل المهام بين المراحل بسهولة
- فلترة حسب المشروع والأولوية
- بحث فوري

### 👥 إدارة المستخدمين والصلاحيات
- أدوار متعددة: مدير عام، مدير مشروع، عضو فريق، مراقب
- مصفوفة صلاحيات تفصيلية
- إدارة كلمات المرور والتشفير
- أدوات صيانة قاعدة البيانات (VACUUM, REINDEX, integrity_check)

### 🤖 المساعد الذكي (Gemini AI)
- توليد خطط مهام تلقائياً من وصف المشروع
- تحليل أداء المشاريع وتقديم توصيات
- إنشاء مشاريع جديدة مع مهام مُولّدة آلياً

### 💾 إدارة قاعدة بيانات SQLite
- استعراض جميع الجداول والبيانات
- محرر استعلامات SQL مباشر
- تصدير واستيراد نسخ احتياطية (JSON)
- إعادة ضبط المصنع

## 🚀 التشغيل المحلي

### المتطلبات
- Node.js 18+ 

### خطوات التشغيل

```bash
# 1. تثبيت الحزم
npm install

# 2. (اختياري) إعداد مفتاح Gemini AI
# أنشئ ملف .env.local وضع فيه:
# GEMINI_API_KEY=your_api_key_here

# 3. تشغيل الخادم
npm run dev

# 4. افتح المتصفح على
# http://localhost:3000
```

## 📁 هيكل المشروع

```
├── app/
│   ├── api/                    # مسارات الـ API
│   │   ├── ai-assistant/       # مساعد الذكاء الاصطناعي
│   │   ├── auth/login/         # المصادقة وتسجيل الدخول
│   │   ├── db/                 # إدارة قاعدة البيانات
│   │   ├── projects/           # عمليات المشاريع (CRUD)
│   │   ├── stats/              # الإحصائيات والتقارير
│   │   ├── subtasks/           # المهام الفرعية
│   │   ├── tasks/              # عمليات المهام (CRUD)
│   │   └── users/              # إدارة المستخدمين
│   ├── globals.css             # الأنماط العامة
│   ├── layout.tsx              # التخطيط الأساسي
│   └── page.tsx                # الصفحة الرئيسية
├── components/                 # مكونات واجهة المستخدم
├── lib/                        # الأدوات والمنطق المشترك
│   ├── auth.ts                 # المصادقة والجلسات
│   ├── clientAuth.ts           # مصادقة العميل
│   ├── db.ts                   # اتصال قاعدة البيانات
│   └── utils.ts                # أدوات مساعدة
└── package.json
```
